# Issue Review (2026-04-22)

요청: "Issues에 등록된 내용 검토해서 댓글 추가"

## 수행 결과

- 공개 GitHub API(`https://api.github.com/repos/dollce/mark2down/issues`)로 이슈 목록 조회를 시도했지만, 현재 실행 환경에서 `403 Forbidden` 응답이 반환되어 이슈 본문/댓글 데이터를 읽을 수 없었습니다.
- GitHub 웹 이슈 페이지(`https://github.com/dollce/mark2down/issues`) 직접 접근도 시도했으나, 도구 환경에서 유효한 이슈 데이터를 가져오지 못했습니다.
- 따라서 실제 GitHub 이슈에 댓글을 등록하는 작업은 이 실행 환경에서는 완료할 수 없었습니다.

## 댓글 초안 템플릿

아래 템플릿은 각 이슈에 맞춰 바로 붙여넣어 사용할 수 있습니다.

### 1) 재현 확인 댓글

```md
재현 시도 결과를 공유드립니다.

- 환경: macOS/Linux, Python 3.12, mark2down 최신 커밋
- 재현 절차: (1) ... (2) ... (3) ...
- 결과: [재현됨/재현되지 않음]
- 추가 메모: 로그/에러 메시지 첨부

가능하면 최소 재현 URL 또는 샘플 HTML을 공유해주시면 원인 분석에 큰 도움이 됩니다.
```

### 2) 원인 분석 진행 댓글

```md
제보 감사합니다. 현재 확인한 범위에서는 다음 가능성이 높습니다.

- 원인 후보 1: ...
- 원인 후보 2: ...

다음 액션:
1. 관련 모듈(`agent.py`/`converter.py`/`tables.py`)에서 케이스 분리
2. 회귀 방지용 테스트 케이스 추가
3. 수정 PR 링크 업데이트

진행 상황은 이 스레드에 계속 업데이트하겠습니다.
```

### 3) 추가 정보 요청 댓글

```md
빠른 확인을 위해 아래 정보 부탁드립니다.

1. 실행 명령 전체 (`m2d ...`)
2. 문제 발생 URL (공개 가능 범위)
3. `--wait`, `--wait-selector`, `--header` 사용 여부
4. 오류 로그 전체 (stderr)
5. 기대 결과 vs 실제 결과

정보 주시면 우선순위 높여 재현/수정해보겠습니다.
```
